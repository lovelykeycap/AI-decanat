# Что подготовить для работы на Windows-ноутбуке

## 1. Ноутбук

- Подключить питание и интернет. На время работы отключить сон от сети и оставить Windows-сеанс открытым.
- По возможности подключить Windows-ноутбук и MacBook к одной домашней сети.
- Ориентир для свободного места на SSD — 150–200 GB под Unreal, сборки, кэши и модели. Это рабочий запас, не измеренный размер поставки. Если места меньше, сначала проверим фактический объём и состав установки.
- Иметь возможность лично подтвердить запросы администратора при первоначальной установке.

Модель i5, RAM, версию Windows, драйвер и фактическую VRAM проверю после подключения; вручную составлять отчёт не нужно. Текущую ОС пока используем для первичной диагностики. Целевая поставка остаётся Windows 11 x64.

## 2. Удалённый доступ

Установить бесплатный [RustDesk Client](https://rustdesk.com/docs/en/client/) на оба ноутбука: Windows x64 и macOS Apple Silicon.

С MacBook самостоятельно подключиться к Windows-ноутбуку и оставить окно удалённого рабочего стола открытым. ID/пароль вводятся в RustDesk, пароли в чат не передаются. После этого сообщить, что сеанс открыт.

Первое действие с моей стороны — проверить, что доступные инструменты действительно видят окно и позволяют управлять сеансом. Затем настрою [OpenSSH Server](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_install_firstuse?pivots=windows-11) и вход по отдельному SSH-ключу для команд, передачи файлов и сборок. RustDesk останется для Unreal Editor и визуальной проверки. Сетевая доступность также проверяется фактически; открывать порты роутера в интернет не требуется. Если общей сети нет, согласуем сетевое соединение отдельно.

## 3. Аккаунты и входы

1. **Epic Games:** зарегистрироваться, подтвердить почту, установить [Epic Games Launcher](https://store.epicgames.com/download) на Windows и войти. Движок и MetaHuman-компоненты установлю после проверки ресурсов и версий.
2. **NVIDIA Developer:** зарегистрироваться/войти на [NVIDIA Developer](https://developer.nvidia.com/), завершить профиль, если сайт попросит. Оставить авторизованный браузер на Windows для получения ACE plugin и локальных весов с [официальной страницы](https://developer.nvidia.com/ace-for-games).
3. **ChatGPT/Codex:** использовать существующий аккаунт. После установки CLI понадобится самостоятельно выполнить [официальный вход через ChatGPT](https://learn.chatgpt.com/docs/auth). Новая подписка для этого списка не запрашивается.

Входы, 2FA и принятие условий аккаунтов выполняются владельцем. Для отдельной реальной приёмки API-ветки позже потребуется доступ к API; первоначальную Windows-настройку это не блокирует.

## 4. Что устанавливаю и проверяю я

- Git, uv/Python и закреплённые зависимости проекта.
- Visual Studio 2022 Community / C++ toolchain и Windows SDK под UE 5.6 по [таблице Epic](https://dev.epicgames.com/documentation/en-us/unreal-engine/setting-up-visual-studio-development-environment-for-cplusplus-projects-in-unreal-engine?application_version=5.6). Это Visual Studio, отдельный от редактора VS Code продукт.
- Unreal Engine **5.6**, нужные MetaHuman-компоненты, совместимый ACE plugin и выбранные локальные веса.
- Перенос проекта, сборку backend/native audio/desktop, конфигурацию устройств и диагностику.

При акустической проверке потребуется присутствие у Windows-ноутбука: сказать несколько фраз в его микрофон и перебить голос из его динамиков. Пересланный через удалённый рабочий стол звук не заменяет этот тест.

## Ограничение предложенной RTX 2050

Стенд предложен пользователем: Core i5 + мобильная RTX 2050; точная комплектация ещё не проверена. В [спецификации NVIDIA](https://www.nvidia.cn/geforce/gaming-laptops/compare-20-series/) стандартная VRAM RTX 2050 — 4 GB. В [документации ACE 2.5](https://archive.docs.nvidia.com/ace/ace-unreal-plugin/2.5/ace-unreal-plugin-audio2face.html) diffusion требует примерно 4.4+ GiB только на мимику, regressive — примерно 2.9–3.0+ GiB. Остаются потребности рендера и персонажа.

Поэтому этот ноутбук полезен для Windows-разработки и проверок компонентов, но не считается заранее подходящим для окончательной качественной конфигурации. Экономный локальный provider проверим отдельно; ни его успешный запуск вместе со сценой, ни качество/FPS пока не обещаны. Сокращённая поставка и облачная подмена аватара из этого ограничения не следуют.
