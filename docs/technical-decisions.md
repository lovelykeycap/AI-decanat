# Технические решения и проверенные факты

Согласованные требования находятся в `product-decisions.md`. Здесь — реализация и результаты проверок, не новые продуктовые требования.

## Среда и зависимости

- Доступная среда — macOS 26.5, arm64. Проект использует изолированный Python 3.12.15; системный Python 3.15 не менялся.
- Точные Python-зависимости закреплены в `uv.lock`. Backend: FastAPI/Pydantic, официальный OpenAI SDK, SQLite, NumPy, Argon2 и keyring.
- Локальный Codex: 0.162.0-alpha.17.2, вход через ChatGPT. Реальный structured-output вызов и двухрепликовый диалог на вымышленном корпусе проверены. Отдельного API-ключа здесь нет; реальный API не проверен.
- Нативный аудиомост собран для arm64 из WebRTC Audio Processing 1.3 и закреплённого Abseil 20230125.1. Это проверка доступной среды, не готовая Windows DLL.

## Разделение процессов и аудио

Python-backend владеет диалогом, поиском и фактически слышимым звуком. Один duplex-поток воспроизводит TTS и получает микрофон, передавая render-reference в WebRTC AEC. Silero VAD и Whisper получают очищенный сигнал. Это конкретизирует исходный план с отдельным аудиослоем и исключает двух независимых проигрывателей.

Whisper small использует CPU по умолчанию: автоматический Metal-режим дал нативный сбой выделения буфера в ограниченной macOS-среде, CPU-прогон прошёл. `whisper_use_gpu` включает ускорение только явно, после проверки нужного backend. Отмена передаётся в штатный whisper.cpp abort callback. Silero синтезирует фрагменты с сохранёнными символьными границами; audio-progress подтверждает их после запланированного DAC-времени. У оборванного фрагмента отдельные слова не угадываются по длительности — это консервативный префикс, не пословное выравнивание.

Unreal C++/Slate-клиент отображает сцену и русский интерфейс, получает события по локальному WebSocket. В первой реализации выбран Slate вместо UMG: интерфейс создаётся кодом без зависимости на отсутствующие widget-assets; пользовательские сценарии сохранены. PCM используется для локального ACE, его собственную слышимую дорожку следует отключить в настоящем персонаже. Синхронизация и сброс уже накопленных кривых должны быть проверены вместе с конкретной версией плагина; один вызов CancelAnimationGeneration не является доказательством мгновенной остановки мимики.

## Целевая ОС и Unreal

Рабочее направление — Windows 11 x64 с NVIDIA: для выбранного локального ACE-provider официальная документация указывает Windows/NVIDIA. Это аргумент выбора, не результат target-build. Проект не расширяется до Linux-поставки параллельно.

Unreal Editor, MetaHuman и локальный ACE-provider на текущем компьютере отсутствуют. Поэтому точная совместимая матрица UE/ACE и Windows hardware minimum ещё не закреплены испытанием. Desktop C++ не компилировался. `Decanat.uproject` намеренно не содержит выдуманный GUID установленного движка; plugin-интеграция активируется только при наличии проверенного ACE через `DECANAT_WITH_ACE=1`.

Готовность UI не разрешает начало голосового разговора без настроенных реальных моделей, аудиоустройства и конфигурации персонажа. Декоративная сцена без человека не считается поставкой аватара.

## База и факты

Внешний формат реализован как ZIP с manifest.json/documents.jsonl. Хранение — SQLite, атомарная замена подготовленного файла. Нет фоновых обновлений во время разговора и нет пользовательской истории версий.

FTS5 и BGE-M3 проверены реальной моделью: индекс построен, 13 сценариев поиска прошли на вымышленном корпусе. При поиске исключены служебные слова из FTS-запроса, чтобы совпадение «мне/что/куда» не поднимало посторонний документ при RRF. Семантическая модель получает полный вопрос и контекст. Её загрузка/прогрев перенесены в старт backend, нативные обращения сериализованы: отмена asyncio-задачи сама по себе не останавливает to_thread-inference. Реальное качество hybrid retrieval на вузовском корпусе ещё не подтверждено. Числовую уверенность модели не используем как доказательство фактов.

Модель BGE-M3: ревизия `5617a9f61b028005a4858fdac845db406aefb181`, CPU, четыре torch-потока. Контрольные суммы весов/конфигурации закреплены в `tools/model-sources.json`; установщик сверяет их до включения, а не просто записывает хеш произвольно полученного файла. Модель не скачивается во время диалога.

Вместо постоянного provider-thread контекст хранится у приложения и передаётся в каждый запрос. Это позволяет переключать провайдер без смешивания студентов. История провайдера не читается с экрана и не парсится из HTML.

## Лицензии и материалы

Собственные исходники не включают чужие веса, коммерческие ассеты и секреты. Установочные инструменты фиксируют происхождение и хеши загруженных моделей. Лицензии сторонних кодов и checkpoints сохраняются отдельно; вывод «бесплатно для любого использования» не делается по лицензии GitHub-репозитория.

MetaHuman-персонаж ещё не создан, визуальный образец и голос не утверждены пользователем. Предварительное направление образа — вымышленный сотрудник со сдержанной деловой внешностью; это подбор ассистента в рамках делегированного решения, не согласованный финальный ассет.
